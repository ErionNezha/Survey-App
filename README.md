# 📊 Sondazhe

Krijo sondazhin tënd, voto dhe shiko rezultatet me grafik të animuar në kohë reale.

Krijo sondazhe, voto dhe shiko rezultatet me grafik të animuar — gjithçka në browser.

## ✨ Veçori

- ➕ Krijim sondazhi: pyetje + 2–6 opsione dinamike (shto/hiq)
- 🗳️ Një votë për sondazh — pastaj kyçet dhe shfaqen rezultatet
- 📊 Bare horizontale të animuara me % dhe numër votash
- ✅ Theksohet opsioni ku votove ti (jeshile)
- 🗑️ Fshirje sondazhi
- 💾 Gjithçka ruhet në localStorage
- 📱 Plotësisht responsive
